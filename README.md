# FestiBites

A responsive Progressive Web Application (PWA) to discover, search, and save delicious cooking recipes with ingredients, step-by-step instructions, and dietary filters.

## Features

- **Recipe Discovery & Search**: Fast real-time search across hundreds of recipes, ingredients, and categories.
- **Dietary & Category Filters**: Filter recipes by category (Desserts, Mains, Quick & Easy, Healthy, etc.) and difficulty.
- **Detailed Recipe Cards & Modals**: View cooking time, servings, difficulty level, structured ingredient lists, and numbered preparation steps.
- **Progressive Web App (PWA)**:
  - Installable on desktop and mobile (iOS & Android).
  - Offline mode with service worker caching.
  - Custom app icons and theme colors.
- **Responsive & Modern UI**: Built with modern CSS custom properties, responsive grid layout, and touch-friendly interface.

## Tech Stack

- **HTML5 & CSS3**: Semantic markup and modern styling with CSS variables, flexbox, and CSS grid.
- **Vanilla JavaScript**: Lightweight, dependency-free interactive recipe filtering, modal handling, and PWA install prompts.
- **Service Worker & Manifest**: Offline caching and full PWA compliance.

## Getting Started

1. Clone or download this repository:
   ```bash
   git clone https://github.com/zaminmohammed78-bit/festibites.git
   ```

2. Open `index.html` directly in your web browser, or serve it using any local HTTP server:
   ```bash
   # Using Python
   python -m http.server 8000

   # Using Node.js (npx)
   npx serve .
   ```

3. Visit `http://localhost:8000` in your browser.
